# dingdong
Use your smartphone to notify people you are there! 

The content of this repository is the backend and the frontend (not yet an app/web-app) of a virtual doorbell project.

If you want to run the backend locally and test it working, do the following:

Run *docker compose up --build* to get the backend working locally

Use the HTML returned to interact with our app! 

If you want to try a real world notification scenario, where you pick your phone to notify, you can use NGROK tunelling to expose the app.

In that scenario, re-do the initial request with the new URL NGROK exposed, and then scan the QR code with your phone! 

Have fun!
